# Deloitte Data Analytics Job Simulation (Forage)
I recently completed the Deloitte Australia Data Analytics Job Simulation on Forage. Here is what I learned in details and in simple terms.

This repo contains my work from Deloitte's **Data Analytics Job Simulation** on
[Forage](https://www.theforage.com/), a fictional consulting engagement for a
client called **Daikibo Industrials**, a multi-factory manufacturing company.

The simulation is split into two independent tasks, each in its own folder:

| Task | Focus | Tools |
|---|---|---|
| [`task-1-tableau-telemetry`](./task-1-tableau-telemetry) | Analyze IoT telemetry from 4 factories to find where machines break down most, and which machine type is the biggest offender | Tableau |
| [`task-2-gender-pay-equality`](./task-2-gender-pay-equality) | Classify a gender pay-equality score per job role/factory into Fair / Unfair / Highly Discriminative bands | Excel |

## About the simulation

Daikibo Industrials wanted help answering two unrelated business questions:

1. **Reliability:** across 4 factories (Tokyo, Osaka, Berlin, Shenzhen), which
   location has the most machine down time, and which device type is driving
   it?
2. **Fairness:** using an internally generated "equality score" per job role
   and location, which roles/locations show fair vs. unfair vs. highly
   discriminatory pay gaps?

## Disclaimer

This is from a Forage virtual job simulation. Daikibo Industrials
is a fictional company created by Forage/Deloitte for training purposes; all
data is synthetic. Raw source datasets provided by Forage are not
redistributed here — see each task's README for how to obtain them.
